# Agent Context Pack (Português)

Bem-vindo. Este pacote ensina aos agentes **como você trabalha**, não os seus dados privados.

> Template público. Identificadores reais foram trocados por placeholders. Ver [`PLACEHOLDERS.md`](PLACEHOLDERS.md).

## Como ler (Camada 1 completa)

1. [`MANIFEST.md`](MANIFEST.md) — orientação e ponteiros
2. [`agent_rules.md`](agent_rules.md) — regras universais
3. [`working-style.md`](working-style.md) — colaboração, pesquisa, engenharia, S/M/C
4. [`appsec-rules.md`](appsec-rules.md) — segurança fail-closed
5. [`senior-implementer-instructions.md`](senior-implementer-instructions.md) — DoD / TDD / staged-write
6. Sob demanda: `identity.md`, `brand-voice.md`, `stack.md`, `about-me.md`, `ux-ui-*.md`
7. Pedidos de domínio → **todas** as IAs usam `[DOMAIN_VAULT]`

## O que não sobe

- Vaults privados (`[OPS_VAULT]` / `[DOMAIN_VAULT]` conteúdo)
- Credenciais
- Quadro real de projetos/clientes (há só [`EXAMPLE_ACTIVE_PROJECTS.md`](EXAMPLE_ACTIVE_PROJECTS.md))
- Changelog privado operacional
